# Portfolio · Penyo Banchev

Live: https://pepoloco.github.io/Portfolio-Project/

A single static page (`index.html` + `media/`), no build step.

## Layout

```
index.html                  the page
media/                      images used by the page (resized)
assets/originals/           source images before resizing (not published)
.github/workflows/pages.yml publishes index.html + media/ to GitHub Pages on every push to main
```

## Editing

Open `index.html` in a browser to preview. Push to `main` (or merge a pull request) to publish.

The "View demo" link points to the dashboards demo, which lives in its own repo:
https://github.com/pepoloco/dashboards
